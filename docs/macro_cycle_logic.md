# 宏观经济周期判断逻辑

## 流程：LLM 优先 → 规则兜底

```
MacroAgent.analyze(macro_data)
  │
  ├─ use_llm=True? → _analyze_llm() → 成功? → 返回 LLM 结果
  │                                      ↓ 失败
  └─ 规则打分 → 连续分段评分 ──────────→ 返回规则结果
```

---

## 一、LLM 路径

### 数据输入（6个指标单点值）

| 指标 | 说明 |
|------|------|
| PMI | 采购经理指数，50=荣枯线 |
| CPI | 消费者价格指数同比 |
| M2 | 广义货币同比增速 |
| PPI | 工业生产者出厂价格同比 |
| 社融 | 当月社会融资规模增量（亿元） |
| SHIBOR_3M | 3月期银行间拆借利率 |

### Prompt 模板

```
你是宏观经济学家。根据以下数据判断经济周期：
PMI=50.5 CPI=1.0% M2=9.0% PPI=0.5% 社融=25000亿 SHIBOR_3M=1.85

回复格式:
周期: [扩张期/复苏期/滞胀期/衰退期]
置信度: [0.0-1.0]
理由: [一句话]
```

### 解析容错

| LLM 输出关键词 | 映射周期 |
|:---|:---|
| 扩张/膨胀/繁荣/过热 | 扩张期 |
| 复苏/回升/回暖 | 复苏期 |
| 滞胀/放缓 | 滞胀期 |
| 衰退/收缩/萧条/低迷 | 衰退期 |

### LLM 配置

- 模型: `Qwen/Qwen3-Next-80B-A3B-Instruct`
- 端点: `http://10.13.66.5:20168/v1`
- max_tokens: 100, temperature: 0.3
- 结果缓存: 按日期去重

---

## 二、规则兜底路径

### 连续分段打分（7档，比旧版5档更细）

| 指标 | 大幅正向 +2/+3 | 温和正向 +1 | 中性 0 | 温和负向 -1 | 大幅负向 -2/-3 |
|------|:---:|:---:|:---:|:---:|:---:|
| **PMI** | ≥55(+3) ≥53(+2) | ≥51(+1) | ≥50(0) | ≥49(-1) | ≥48(-2) <48(-3) |
| **CPI** | >5(+2) | >3(+1) | >1(0) | ≥0(-1) | <0 通缩(-2) |
| **M2** | >13(+2) | >10(+1) | >8(0) | >6(-1) | ≤6(-2) |
| **社融** | >1.3×MA(+2) | >1.1×MA(+1) | >0.9×MA(0) | >0.7×MA(-1) | ≤0.7×MA(-2) |

### 趋势动量加分

- PMI 当前值 > 3月均线 → +1（上升趋势）
- PMI 当前值 < 3月均线 → -1（下降趋势）

### 周期判定

| 得分范围 | 周期 | 默认置信度 |
|:---:|------|:---:|
| ≥5 | 扩张期 | 80% |
| 2 ~ 4 | 复苏期 | 65% |
| -2 ~ 1 | 滞胀期 | 55% |
| -5 ~ -3 | 衰退期 | 70% |
| <-5 | 衰退期 | 85% |

## 三、数据来源

- 结果缓存到 `cache/holdings_{date}.json`
