# ETF 评分公式（当前版本）

## 一、原始指标计算

数据源：`local_store.get_bars()` → 日线 OHLC（130天）

| 指标 | 计算方式 | 范围 |
|------|---------|------|
| `pos_60` | (最新价 - 60日最低) / (60日最高 - 60日最低) | 0~1 |
| `pos_120` | (最新价 - 120日最低) / (120日最高 - 120日最低) | 0~1 |
| `mom_21d` | 最新价 / 21日前收盘 - 1 | 原始值 |
| `ann_vol` | log收益标准差 × √252 | 原始值 |

## 二、综合评分

```python
pos60   = metrics.get("pos_60", 0.5)          # 60日位置
pos120  = metrics.get("pos_120", 0.5)         # 120日位置
mom_raw = metrics.get("mom_21d", 0)           # 21日动量
vol     = metrics.get("ann_vol", 0.3)         # 年化波动率

# 动量归一化: [-0.5, +0.5] → [0, 1]
mom = max(-0.5, min(0.5, mom_raw)) + 0.5

# 波动率惩罚: 越低越好, 0.6 对应得分 0
vol_s = max(0, 1 - vol / 0.6) if vol > 0 else 0.5

# 加权综合
score = pos60 * 0.35 + mom * 0.25 + pos120 * 0.20 + vol_s * 0.20
```

| 权重 | 维度 | 含义 |
|:----:|------|------|
| 35% | pos_60 | 中期趋势位置（最重） |
| 25% | mom_21d | 近期动量方向 |
| 20% | pos_120 | 长期趋势位置 |
| 20% | vol_s | 波动率惩罚（低波加分） |

## 三、选股流程

1. 按评分降序排列候选 ETF
2. 同指数去重（`_extract_index` 匹配沪深300/科创50等关键词），只留最高分
3. TOP_N 截断：Stock=5, Bond=2, Commodity=2
4. 权重 = 类别目标权重 × (该ETF得分 / 该类总得分)
5. 混合置信度平滑：`w * confidence + (1/N) * (1 - confidence)`
6. 最低权重过滤：<2%且 >2只时剔除

## 四、相关性去重（仅回测）

- 股票类内 22日滚动相关性
- 残差阈值 0.95
- 去掉得分较低的，至少保留 3 只

## 五、风险控制

- `max_gold_ratio`: 45%
